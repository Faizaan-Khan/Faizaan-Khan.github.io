Doremon privacy policy

Last updated: November 26, 2026

Who uses it

Doremon is a personal app used only by its author, Faizaan Khan. It has no other users.

What it accesses

  • Gmail: sender, subject, date and a short preview of recent inbox messages, to show which ones need a reply.
  • Google Calendar: today's and tomorrow's events.
  • Google Sheets: the author's own task spreadsheet.

Where the data goes

  • The data is processed on the author's own computer. Google sign-in tokens are stored there in files only his account can read.
  • To sort email, the sender, subject and preview of recent messages are sent to Anthropic's Claude service, which returns a category. No tools or actions are available to Claude in that step.
  • Telegram receives only short notifications with counts (for example "3 emails need you"), never email or calendar contents. Details are shown on a private page reachable only from the author's own devices over a private network.
  • Data is not sold, not used for advertising, and not shared with anyone else.

Google user data

Doremon's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the stored token file on the author's computer removes Doremon's access immediately.
